## Email in development

Messages are captured by Letter Opener Web and are not delivered to a real inbox.

http://localhost:3000/letter_opener

Set `MAILER_FROM` when you are ready to send production mail, and `SMTP_URL` or `CLOUDMAILIN_SMTP_URL` for SMTP. Production SMTP is ignored in development so local sign-up and password emails stay in Letter Opener.
